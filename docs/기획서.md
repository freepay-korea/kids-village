# 아이 게임 마을 기획서 (가칭)

작성일: 2026-10-09 · 원본 문서: https://claude.ai/code/artifact/d22aa60c-b06b-47dc-b528-fb7395e4dd5a

## 개요

2~5세 아이가 마을 지도에서 건물을 골라 미니게임을 하는, 광고 없는 무료 종합 게임 앱이에요. 예전 네이버 주니어·야후 꾸러기의 플래시 게임 모음을 지금 아이들 눈높이로 다시 만드는 게 목표예요.

**목표**

- 앱 하나, 홈페이지 하나로 모든 게임을 제공 (기존 부릉부릉 놀이터·콕콕 단어도 마을 건물로 편입)
- 첫 출시 5개 건물, 이후 건물을 하나씩 추가하는 업데이트 구조
- 부모가 안심하고 쥐여줄 수 있는 앱: 광고·외부 링크·결제·데이터 수집 없음

**핵심 원칙**

1. 글 몰라도 된다: 모든 안내는 그림 + 소리(TTS), 버튼에 글자 의존 없음
2. 실패가 없다: 틀려도 벌점·게임오버 없이 부드러운 재시도, 맞히면 크게 칭찬
3. 탭 한 번에 반응: 어디를 눌러도 소리나 움직임이 나와야 함
4. 짧게 끝난다: 게임 한 판 1~3분, 끝나면 스티커 보상
5. 큰 터치 영역: 최소 64px, 화면 가장자리 오조작 방지

## 마을 허브와 화면 흐름

앱을 켜면 바로 마을 지도가 나오고, 모든 게임은 마을에서 들어가 마을로 돌아오는 한 가지 흐름을 따라요.

```
앱·홈페이지 시작 → 마을 지도 → 건물 선택 → 놀이·미션 모드
                     │  ▲                         │ 미션 완료
       어른만: 3초    │  │ 마을로 복귀              ▼
       길게 누르기    ▼  └── 스티커북에 보관 ◀── 스티커 획득
                 부모 설정
```

어느 게임에서든 왼쪽 위 집 버튼을 누르면 바로 마을로 돌아오고, 스티커북은 마을 입구에서 언제든 열 수 있어요.

**마을 지도 화면**

- 가로로 살짝 스크롤되는 마을 한 장, 건물 5개 + 스티커북(마을 입구) + 빈 공터(다음 업데이트 예고, "곧 열려요" 공사 중 표시)
- 건물 탭 → 마스코트가 건물 이름을 말하고 문이 열리며 확대 전환
- 건물 위에 그 건물에서 모은 스티커 수가 작은 별로 표시
- 시간대 연출: 놀이 시간 알림이 오면 마을이 노을빛으로 바뀜

## 첫 출시 게임 5종

다섯 건물 모두 "놀이 모드(자유롭게 탭)"와 "미션 모드(짧은 과제 후 스티커)"를 갖춰요. 2세는 놀이 모드만 해도 충분히 재밌고, 4~5세는 미션으로 성취감을 얻는 구조예요.

| 건물 | 연령 | 놀이 모드 | 미션 모드 | 스티커 조건 |
| --- | --- | --- | --- | --- |
| 부릉부릉 차고 | 2세~ | 소리 도감: 탈것 탭하면 소리·애니메이션 | 세차장: 거품 문지르기 → 물 뿌리기 → 반짝 | 세차 1대 완료 |
| 콕콕 단어 학교 | 2세~ | 그림 탭하면 단어 소리 | "사과 어디 있지?" 2~4장 중 찾기, 5문제 | 5문제 완료 |
| 동물 농장 | 2세~ | 동물 탭하면 울음소리·점프 | "음메~ 누구 소리지?" 소리 듣고 동물 찾기, 5문제 | 5문제 완료 |
| 풍선 공원 | 2세~ | 떠오르는 풍선 터뜨리기 (터질 때 색 이름 소리) | "빨간 풍선 3개 터뜨려!" 색·숫자 지시 따르기 | 미션 3개 완료 |
| 미술관 | 3세~ | 손가락 색칠, 스탬프 찍기 | 밑그림(동물·탈것) 색칠 후 "다 했어" 버튼 | 그림 1장 완성, 갤러리 저장 |

**난이도 조절 (4~5세)**

- 콕콕 단어·동물 농장: 보기 수 2장 → 3장 → 4장으로 자동 증가 (연속 정답 시)
- 풍선 공원: 풍선 속도와 지시 복잡도 증가 ("빨간색" → "빨간 풍선 3개")
- 부모 설정에서 "쉬움 고정" 가능

**틀렸을 때**

- 오답 그림은 살짝 흔들리고 "다시 찾아볼까?" 소리, 점수 감점 없음
- 같은 문제 2번 틀리면 정답이 반짝이며 힌트

**이후 추가 후보 건물**: 카드 짝 맞추기, 조각 퍼즐, 미로 길 찾기, 다른 그림 찾기, 숫자 세기 빵집, 부릉부릉의 길 그리기·정비소·공사장 (기존 3세~ 모드)

## 공통 시스템

모든 게임이 같은 공통 모듈을 쓰고, 게임은 "시작·끝·스티커 지급" 신호만 주고받아요.

**스티커북**

- 미션 완료 시 그 건물의 스티커 1장 지급, 건물마다 10~20종
- 마을 입구의 스티커북에서 모은 스티커를 보고, 빈 배경판에 자유롭게 붙이기
- 저장은 기기 안(localStorage/Capacitor Preferences)에만, 계정·서버 없음

**마스코트 안내**

- 마을 곳곳에서 마스코트가 TTS로 안내 ("여기는 동물 농장이야!")
- 문장은 게임별 대사 파일(ko.json)로 관리, 영어 추가 시 en.json만 늘림
- TTS는 기기 내장 음성 사용 (웹: Web Speech API, 앱: Capacitor TTS 플러그인)

**부모 잠금**

- 설정 화면 진입은 "버튼 3초 길게 누르기" 또는 간단한 덧셈 문제
- 설정 항목: 소리 크기, 배경음 켜기/끄기, 난이도 쉬움 고정, 놀이 시간 알림(15/30분), 스티커 초기화
- 놀이 시간 알림: 마스코트가 "이제 쉬어볼까?" 하고 마을이 저녁으로 바뀜 (강제 종료는 안 함)

**안전 원칙**

- 외부 링크 없음 (개인정보처리방침은 부모 잠금 안에만)
- 인터넷 없이 동작 (첫 실행 후 오프라인 플레이, PWA 캐시)
- 개인정보·분석 SDK 수집 없음 → Play 데이터 보안 "수집 없음", 가족 정책(Designed for Families) 대응 쉬움

## 디자인·사운드

밝고 둥근 그림책 느낌으로 통일하고, 모든 건물이 같은 색·폰트·버튼 규칙을 따라요.

- 그림: MVP는 Fluent Emoji(MIT) + 단순 도형, 출시 전 일관된 일러스트로 교체 (콕콕 단어에서 정한 방침 그대로)
- 색: 건물마다 대표색 1개 (차고 주황, 학교 노랑, 농장 초록, 공원 하늘, 미술관 보라), 배경은 파스텔
- 폰트: 둥근 고딕 계열 (예: Jua, 무료), 글자는 장식용이고 정보는 그림·소리로 전달
- 화면: 가로 모드 고정, 태블릿·폰 모두 대응, 홈 버튼은 항상 왼쪽 위 집 아이콘
- 효과: 탭마다 작은 반짝임, 정답·스티커 획득 시 큰 축하 (색종이·별 터짐)
- 소리: 효과음은 무료 라이선스(Kenney CC0 등), 배경음은 건물별 짧은 루프, 볼륨은 부모 설정
- 진동: 앱에서 정답 시 짧은 햅틱 (설정에서 끔 가능)

## 기술 구조

코드 하나를 웹으로 빌드해 홈페이지에 올리고, 같은 빌드를 Capacitor로 감싸 앱으로 내요.

**스택**: React + Vite + TypeScript + Tailwind + PixiJS v8(게임 화면) + Framer Motion(UI 애니메이션) + Howler(소리) + Zustand(상태) + vite-plugin-pwa + Capacitor

**폴더 구조**

```
src/
  app/            라우팅, 마을 허브, 부모 잠금
  core/           스티커, 저장, TTS, 사운드, 설정, i18n
  ui/             공통 버튼·홈 버튼·축하 효과
  games/
    registry.ts   건물 목록 (한 줄 추가 = 건물 추가)
    garage/       부릉부릉 차고
    word-school/  콕콕 단어 학교
    farm/         동물 농장
    balloon-park/ 풍선 공원
    art-museum/   미술관
public/assets/    그림·소리 (건물별 폴더)
docs/             기획서, 게임별 스펙
CLAUDE.md         클로드 코드용 규칙
```

**게임 플러그인 규약**

- 각 게임은 `{ id, name, icon, color, minAge, locked, load }`를 registry에 등록
- `load()`는 동적 import → 마을 첫 화면이 가볍고, 건물 들어갈 때만 해당 게임 로딩
- 게임은 `onComplete(stickerId)`, `onExit()` 두 신호만 호출, 스티커·저장은 core가 처리
- `locked`는 지금 모두 false (유료화 대비 자리)

**배포**

- 홈페이지: main 브랜치 push 시 GitHub Actions로 자동 배포 (GitHub Pages 또는 Vercel)
- 앱: `npm run build && npx cap sync android` → Android Studio에서 AAB 생성, Play Console 업로드
- 쫄에서 겪은 것 미리 반영: safe-area·전체화면(immersive), gradlew 실행권한, 업로드 키 별도 보관

## 기존 앱 이식 계획

두 앱 모두 아직 출시 전이라 별도 앱으로 내지 않고, 만들어둔 기획과 시제품을 마을 건물로 옮겨요.

| 기존 앱 | 가져올 것 | 첫 출시 범위 | 나중에 |
| --- | --- | --- | --- |
| 부릉부릉 놀이터 | 시제품 HTML(소리 도감·세차장), 모드 구조, 개발 가이드 | 소리 도감 + 세차장 | 길 그리기 드라이브, 정비소, 공사장 (3세~) |
| 콕콕 단어 | 단어 찾기 규칙, 42단어 목록, TTS 방침 | 한국어 단어 찾기 | 영어 전환, 단어 확장 |

- 부릉부릉 시제품은 단일 HTML이라 PixiJS 컴포넌트로 다시 짜되, 이펙트·소리 타이밍은 시제품을 기준으로 맞춤
- 콕콕 단어의 42단어는 와이프와 확정 예정이었던 목록을 그대로 쓰고, 동물 농장과 동물 그림·소리를 공유
- 두 앱의 기존 개발 가이드(제미나이용)는 참고 자료로만 docs/에 보관

## 클로드 코드 작업 순서

한 단계 = 클로드 코드 세션 하나로 잡고, 단계마다 웹에서 직접 눌러보고 넘어가요. 각 단계 시작 시 "CLAUDE.md와 docs/기획서 읽고 N단계 진행해줘"라고만 지시하면 돼요.

1. **뼈대**: 저장소 생성, Vite+React+TS+Tailwind 세팅, CLAUDE.md·docs/ 작성, 웹 자동 배포까지
2. **마을 허브**: 마을 지도, 건물 5개(빈 건물), 홈 버튼, 건물 진입·복귀 전환 효과
3. **공통 core**: 사운드, TTS, 저장, 설정, 부모 잠금, 축하 효과
4. **스티커북**: 스티커 지급·보관·붙이기 화면
5. **동물 농장**: 첫 게임으로 플러그인 규약 검증 (가장 단순)
6. **콕콕 단어 학교**: 동물 농장 구조 재사용
7. **풍선 공원**
8. **부릉부릉 차고**: 시제품 이식 (소리 도감 + 세차장)
9. **미술관**: 색칠·스탬프·갤러리 저장
10. **PWA·오프라인**: 설치·캐시, 아이콘·스플래시
11. **앱 빌드**: Capacitor 안드로이드, safe-area, 전체화면, 햅틱, AAB 생성
12. **점검**: 실제 폰·태블릿에서 아이 테스트, 오조작·소리 크기 조정

**CLAUDE.md에 넣을 규칙**

- 모든 안내는 그림+TTS, 글자 의존 UI 금지 / 터치 영역 64px 이상
- 외부 링크·광고·분석 SDK·결제 코드 추가 금지
- 새 게임은 games/ 아래 폴더 + registry 한 줄, core 직접 수정 최소화
- 작업 끝나면 `npm run build` 통과 확인 후 커밋

## 출시 체크리스트와 로드맵

**출시 전**

- [ ] 개인정보처리방침 페이지 (수집 없음 명시)
- [ ] Play 타겟층: 5세 이하 선택 → 가족 정책(Designed for Families) 준수 확인

- [ ] 데이터 보안: 수집·공유 없음
