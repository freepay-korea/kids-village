# 안드로이드 앱 빌드 (12단계)

같은 코드를 Capacitor로 감싸 앱으로 낸다. 웹 빌드와 다른 점은 `base`가 `/`라는 것뿐이다.

## 테스트용 APK 받기 (설치 없이)

`main`에 push될 때마다 GitHub Actions(`.github/workflows/android.yml`)가 디버그 APK를 만들어
저장소 **Releases → "테스트용 APK (최신 main)"** 에 `kids-village-debug.apk`로 올려요.
폰에서 그 파일을 내려받아 설치하면 돼요("출처를 알 수 없는 앱" 허용 필요). Actions 탭의 아티팩트에서도 받을 수 있어요.

## 이미 되어 있는 것

- `android/` 폴더는 생성되어 커밋돼 있어요 (`npx cap add android` 다시 할 필요 없음)
- 가로 고정(`sensorLandscape`), 전체화면(immersive), 화면 꺼짐 방지는 `AndroidManifest.xml`·`MainActivity.java`에 반영
- 런처 아이콘·스플래시는 `public/icons/icon.svg`로 렌더해 `android/app/src/main/res/`에 들어 있음
- `android/gradlew` 실행권한 설정됨

## 앱 ID 바꾸기

지금 앱 ID는 `com.freepaykorea.kidsvillage`예요. **Play에 올리기 전까지는** 바꿀 수 있어요. 바꿀 곳:

1. `capacitor.config.ts`의 `appId`
2. `android/app/build.gradle`의 `namespace`와 `applicationId`
3. `android/app/src/main/res/values/strings.xml`의 `package_name`, `custom_url_scheme`
4. `android/app/src/main/java/com/freepaykorea/kidsvillage/MainActivity.java`의 `package` 줄과 폴더 경로

## Play 스토어용 서명 빌드 (Android Studio 필요)

1. Android Studio 설치, JDK 21
2. 업로드 키(keystore)는 저장소 밖에 별도 보관

## 매번 하는 것

```bash
npm run build:app
npx cap open android        # Android Studio → Build → Generate Signed Bundle (AAB)
```

## 앱에서 확인할 것 (6단계 중간 확인 항목)

- [ ] 소리: "탭해서 시작" 후 효과음·음성이 나는지 (WebView는 첫 터치 전 소리 차단)
- [ ] 터치: 64px 버튼이 손가락으로 잘 눌리는지, 풍선·세차장 드래그
- [ ] 가로 고정: 세로로 돌려도 화면이 돌지 않는지 ("폰을 돌려주세요"가 뜨면 안 됨)
- [ ] safe-area: 노치·네비게이션 바가 홈 버튼·팔레트를 가리지 않는지
- [ ] 뒤로가기 버튼: 게임에서 마을로, 마을에서는 앱이 꺼지지 않는지
- [ ] 저장: 앱을 껐다 켜도 스티커·설정·갤러리가 남아 있는지

## 코드에서 앱 전용으로 동작하는 것

- `src/core/haptics.ts`: 정답 진동 (Capacitor Haptics)
- `src/core/native.ts`: 뒤로가기 버튼, 백그라운드 시 음성 정지
- `src/core/storage.ts`: 지금은 localStorage. WebView에서도 유지되지만, 필요하면 Capacitor Preferences로 교체
