# 안드로이드 앱 빌드 (12단계)

같은 코드를 Capacitor로 감싸 앱으로 낸다. 웹 빌드와 다른 점은 `base`가 `/`라는 것뿐이다.

## 한 번만 하는 준비

1. **앱 ID 확정** (`com.○○.○○`, 출시 후 변경 불가) → `capacitor.config.ts`의 `appId` 교체
2. Android Studio 설치, JDK 17
3. 안드로이드 프로젝트 생성
   ```bash
   npm run build:app          # VITE_BASE=/ 로 빌드 + cap sync
   npx cap add android        # android/ 폴더 생성 (최초 1회)
   chmod +x android/gradlew   # 쫄에서 겪은 실행권한 문제
   ```
4. `android/app/src/main/AndroidManifest.xml`의 `<activity>`에 추가
   ```xml
   android:screenOrientation="sensorLandscape"
   ```
5. 전체화면(immersive): `android/app/src/main/java/.../MainActivity.java`
   ```java
   @Override
   public void onWindowFocusChanged(boolean hasFocus) {
     super.onWindowFocusChanged(hasFocus);
     if (hasFocus) {
       getWindow().getDecorView().setSystemUiVisibility(
         View.SYSTEM_UI_FLAG_IMMERSIVE_STICKY
         | View.SYSTEM_UI_FLAG_LAYOUT_STABLE
         | View.SYSTEM_UI_FLAG_LAYOUT_HIDE_NAVIGATION
         | View.SYSTEM_UI_FLAG_LAYOUT_FULLSCREEN
         | View.SYSTEM_UI_FLAG_HIDE_NAVIGATION
         | View.SYSTEM_UI_FLAG_FULLSCREEN);
     }
   }
   ```
6. 아이콘·스플래시: `public/icons/icon.svg`를 바탕으로 Android Studio의 Image Asset으로 생성 (또는 `@capacitor/assets`)
7. 업로드 키는 저장소 밖에 별도 보관

## 매번 하는 것

```bash
npm run build:app
npx cap open android        # Android Studio → Build → Generate Signed Bundle (AAB)
```

## 앱에서 확인할 것 (6단계 중간 확인 항목)

- [ ] 소리: "탭해서 시작" 후 효과음·음성이 나는지 (WebView는 첫 터치 전 소리 차단)
- [ ] 터치: 64px 버튼이 손가락으로 잘 눌리는지, 풍선·세차장 드래그
- [ ] 가로 고정: 세로로 돌려도 화면이 돌지 않는지 ("폰을 돌려주세요"가 뜨면 안 됨)
- [ ] safe-area: 노치·네비게이션 바가 홈 버튼·팔레트를 가리지 않는지
- [ ] 뒤로가기 버튼: 게임에서 마을로, 마을에서는 앱이 꺼지지 않는지
- [ ] 저장: 앱을 껐다 켜도 스티커·설정·갤러리가 남아 있는지

## 코드에서 앱 전용으로 동작하는 것

- `src/core/haptics.ts`: 정답 진동 (Capacitor Haptics)
- `src/core/native.ts`: 뒤로가기 버튼, 백그라운드 시 음성 정지
- `src/core/storage.ts`: 지금은 localStorage. WebView에서도 유지되지만, 필요하면 Capacitor Preferences로 교체
